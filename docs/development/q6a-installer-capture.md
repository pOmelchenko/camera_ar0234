# Проверка установщика AR0234 и захвата RAW10 на Q6A

Установщик проверен на тестовых записях EFI и DTB. Установка скриптом,
загрузка платы с полученной конфигурацией и захват через V4L2 ещё требуют
проверки на физической Q6A. Для первого прогона выбран **CAM2/J16**. На этом
разъёме уже проверены [ручная установка и захват через libcamera](../guides/sbc/radxa_dragon_q6a.md).

## Установка

По умолчанию скрипты используют `cam2`. Для проверки другого разъёма
укажите `cam1` (J14) или `cam3` (J7) при установке и захвате.

**С Mac или Linux** в корне репозитория камеры:

```sh
sh target/sbc/radxa_dragon_q6a/deploy.sh radxa@radxa-dragon-q6a.local cam2
```

Команда доставляет комплект в `~/q6a-ar0234` и запускает установку по SSH.
**Для локальной установки** скопируйте весь `target/sbc/radxa_dragon_q6a`
на плату или откройте его в клоне репозитория, затем выполните:

```sh
sudo python3 install.py --port cam2
```

Установщик применяет оверлеи к временной копии DTB и проверяет выбранную
пару CCI/CSIPHY, соседние маршруты и привязанные устройства I²C, SPI и DSI.
На свободном порту он добавляет AR0234 в текущую запись EFI. На уже настроенном
порту проверяет действующий маршрут. Для другого сенсора показывает прежний
оверлей и спрашивает разрешение на замену. Enter отменяет замену. Для запуска
без диалога добавьте `--replace` в конец команды. Встроенный в базовый DTB
сенсор и профиль с посторонней периферией требуют ручной настройки.

Если для текущего ядра отсутствует модуль `ar0234`, установщик запрашивает через
APT инструменты сборки и заголовки этого ядра, проверяет SHA-256 закреплённых
исходников Kurokesu и собирает модуль через `make driver`. Для первой сборки
нужны доступ к источникам и пакеты Radxa. При обновлении ядра запустите
установщик для новой версии. Утилиты `dtc`, `media-ctl`, `v4l2-ctl` и `kmod`
также устанавливаются по необходимости. Уже установленный драйвер используется повторно.

Перед первым изменением существующих конфигурационных файлов создаются копии
`*.before-ar0234`. Отключённый оверлей выбранной камеры в каталоге `dtbo/`
получает суффикс `.disabled`. Другие записи EFI, которые его использовали,
получают ссылку на копию того же DTBO в `ar0234-saved-overlays/`.
Для отката сначала скопируйте прежний DTBO из `.disabled` под исходным именем,
затем восстановите нужную запись EFI и, если менялся, `loader.conf` из копий.
Состояние этих копий соответствует первой установке. Настройки автозагрузки
модулей находятся в `/etc/modules-load.d/q6a-ar0234.conf`.

## Захват

Если установщик сообщил об изменении загрузочной конфигурации, выполните
`sudo reboot`. После загрузки откройте на плате каталог комплекта
(при доставке по SSH — `cd ~/q6a-ar0234`) и выполните:

```sh
python3 capture.py --port cam2
```

Скрипт выбирает сенсор по связи с физическим CSIPHY и проверяет согласованный
формат `pgAA` (Bayer GRBG, упакованный RAW10) и размер 1920×1200.
В отдельном каталоге `ar0234-…` появятся `frame.raw` с полным шагом строки
и `preview.ppm` 960×600. Каждый пиксель превью получен из одного блока GR/BG
с усреднением зелёного.

## Что записать при проверке на плате

В [каталоге результатов Q6A](../../target/sbc/radxa_dragon_q6a/validation/)
укажите версию комплекта, ядро, разъём, кабель и прежнюю конфигурацию камер.
Сохраните команду и результат установки, выбранную запись EFI и результат
загрузки. Для захвата запишите маршрут media graph, согласованный формат,
ширину, высоту и шаг строки. Сверьте размер `frame.raw` с размером буфера
V4L2 и откройте `preview.ppm`. После успешной проверки опишите в руководстве
порт и способ установки, которые прошли этот прогон.
