# Просмотр AR0234 с шумоподавлением

Из терминала рабочего стола Q6A, в каталоге этой платформы:

```sh
make demo
sh tools/preview.sh
```

При запуске включён лёгкий фильтр. Сначала libcamera преобразует RAW10 в RGB;
шейдер OpenGL ES 3 корректирует изолированные яркие выбросы и сглаживает
пространственный и временной шум. В тенях обработка сильнее, особенно для
цветных крапинок. История хранится в RGBA16F, чтобы округление до 8 бит
не замораживало мелкие изменения. При движении накопление уменьшается.

| Клавиша | Действие |
| --- | --- |
| N | Включить/выключить фильтр |
| C | Сравнение: слева исходник, справа обработанный кадр |
| 1 / 2 / 3 | Лёгкий / средний / сильный фильтр |
| F | Полный экран |
| Esc / Q | Закрыть окно и освободить камеру |

Окно должно иметь фокус. В заголовке показаны режим и частота кадров.
По умолчанию запрашивается 1920×1200; проверенный ISP выдаёт 1912×1200,
stride 7680 байт. Демка учитывает восемь дополнительных пикселей в stride.
Если обработка не успевает, просмотр выбирает свежий кадр и считает пропуски.

Проверка шейдера без захвата камеры, в той же графической сессии:

```sh
make check
```

Проверка живого потока и снимок сравнения в новом каталоге:

```sh
capture_dir=$(mktemp -d "$HOME/ar0234-demo.XXXXXX")
sh tools/preview.sh --compare --frames=600 --snapshot="$capture_dir/comparison.ppm"
```

Остановить предыдущий просмотр перед захватом. `--snapshot` используется
вместе с ограничением числа кадров; PPM содержит исходник слева и результат
справа. `--width=1280 --height=720` меняет запрашиваемый выходной размер.

На Q6A проверены 600 кадров: 59,5262 кадров/с, семь пропусков просмотра,
ноль ошибок захвата. Для синтетической неподвижной сцены лёгкий фильтр дал
RMS шума 0,596 от исходного. В отдельном тесте теней режимы 1/2/3 дали
0,163/0,115/0,113, сохранив 94/93/92% контраста тусклой тонкой линии.
Это результаты тестовых сцен; они не означают такое же подавление любого
шума камеры. Полные показатели — в [записи проверки](../validation/2026-10-11.json).

Сильный фильтр может сглаживать детали и оставлять шлейфы. Коррекция точек
выполняется после дебайеризации: это не карта дефектных пикселей и не
калибровка чёрного уровня. Демка не меняет усиление, экспозицию или драйвер.
Пересвет и отражения объектива этой обработкой не исправляются.

Прежний просмотр через `cam`: `sh tools/preview-original.sh`.
