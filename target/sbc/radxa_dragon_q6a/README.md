# AR0234 на Radxa Dragon Q6A

**Статус: драйвер собран и установлен; физический захват на CAM2 проверен.**
На Ubuntu 24.04.5 LTS / `7.0.11-7-qcom` получен цветной поток RAW10
1920×1200 по двум линиям CSI, около 60 кадров/с. Software ISP libcamera
выдаёт 1912×1200. Точная ревизия модуля и схема переходника не зафиксированы.

## Запуск

Полный рабочий путь — [инструкция Q6A](../../../docs/guides/sbc/radxa_dragon_q6a.md):
сборка, установка модуля и overlay, резервная загрузка, захват и восстановление.
После настройки камеры из терминала рабочего стола, в этом каталоге:

```sh
make demo
sh tools/preview.sh
```

Демка показывает полный кадр с шумоподавлением. `N` включает фильтр,
`C` сравнивает исходник и результат, `1/2/3` выбирает силу, `F` включает
полный экран, `Esc` закрывает окно. Подробнее — [демка](demo/README.md).
Простой просмотр: `sh tools/preview-original.sh`.

## Подключение

| Сторона | Интерфейс | Область проверки |
| --- | --- | --- |
| Заказанный AR0234 MIPI | Цветной сенсор, ID `0x0a56`, выбранный объектив 200° | Захват работает; маркировка DECXIN-3478V1 относится к материалам продавца |
| Q6A J16 / CAM2 | 15 контактов, 1 мм; две линии | Проверен маршрут `cci1_i2c0` → CSIPHY2, адрес `0x10` |
| Q6A J14 / CAM1 | 31 контакт, 0,3 мм; четыре линии | Не проверен с этой камерой |
| Q6A J7 / CAM3 | 15 контактов, 1 мм; две линии | Не проверен с этой камерой |

По [Radxa CSI](https://docs.radxa.com/en/dragon/q6a/hardware-use/mipi-csi)
J16/J7 имеют распиновку Raspberry Pi. Модуль из документов имеет собственный
22-контактный FPC: DECXIN 1 = 3,3 В, а RPi22 1 = GND. Рабочий экземпляр
подключён к CAM2, но тип кабеля/переходника и его поконтактная схема
не зафиксированы. Эту схему нельзя восстановить только по факту захвата.
См. [распиновку камеры](../../../docs/reference/pinout.md) и
[аппаратный справочник платы](https://github.com/pOmelchenko/radxa_dragon_q6a/blob/main/docs/reference/hardware.md#камерные-разъёмы).
Уровни и временной контракт J2 TRG/STRB ещё не проверены.

## Ограничения

Драйвер необходимо пересобирать под новое ядро. libcamera использует
`uncalibrated.yaml`, без AR0234 sensor helper; цвет, усиление и экспозиция
не откалиброваны. Warm reboot проверен; cold power-on, длительный прогон,
120 кадров/с и внешний trigger не проверены. Причина полос от ламп
не установлена. Наличие работающего примера не подтверждает другой модуль,
кабель, BSP или разъём.
